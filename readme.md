# Sparse Matrix Multiplication Using CSR

This project implements sparse matrix-vector multiplication using the
Compressed Sparse Row (CSR) representation in C.

## Files

- `challenge.c` → Code implementation
- `readme.md` → Documentation
- `RV_Sparse.pdf` → Compiled report

## Features

- CSR conversion
- Sparse matrix-vector multiplication
- No dynamic memory allocation inside the function
- Randomized test harness for verification
